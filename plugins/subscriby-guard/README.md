# Subscriby Guard

A companion to the `subscriby` plugin: one `PreToolUse` hook whose matcher is the generated list of every Subscriby MCP tool the catalogue flags destructive. When Claude is about to call one, the hook answers with a permission decision of **ask**, so Claude Code shows the call and waits for you, whatever the session's permission settings say, even when the server is auto-approved.

```
/plugin marketplace add envigoinnovations/subscriby-agentic-kit
/plugin install subscriby@envigo
/plugin install subscriby-guard@envigo
```

It is a separate plugin because it is a command hook, which Anthropic's plugin directory accepts only from organizations it has verified; the kit's listing there carries no hook, and the marketplace carries both plugins. Without the guard, Claude Code's own permission prompt still covers every tool unless you auto-approve the server, and the skills confirm every destructive change in conversation before the tool is called.

`hooks/hooks.json` is generated by `npm run sync` from the tool catalogue, never edited by hand; `hooks/ask-before-destructive.sh` is the answer, a plain shell command with no dependencies that reads nothing from the call and changes no argument. The plugin carries the kit's version and updates with it; the marketplace's [README](../../README.md) describes the kit, and the documentation lives at [docs.subscriby.net/integrations/agentic-kit/safety](https://docs.subscriby.net/integrations/agentic-kit/safety).
