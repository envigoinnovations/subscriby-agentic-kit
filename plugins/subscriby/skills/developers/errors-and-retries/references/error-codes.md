# Error codes: Errors and Retries

Generated from the Subscriby catalogue (version 2026-05-01) by `npm run sync`; `npm run check` fails on a hand edit. Every error is `{"error": {"code", "message", "docs_url", "remediation", "request_id"}}`; branch on `code`, a stable string, and quote `request_id` when asking for help.

| Code | HTTP | Default message | Remediation | Docs |
| --- | --- | --- | --- | --- |

| `AUTHENTICATION_REQUIRED` | 401 | A valid API token is required for this endpoint. | Send the request with an Authorization: Bearer <sbt_...> header using a token minted at /settings/tokens. | https://docs.subscriby.net/api/v1/errors#authentication-required |
| `TOKEN_MISSING_ABILITY` | 403 | The presented API token does not carry the ability required to perform this action. | Mint a new token including the ability listed in error.required_ability, or ask the team owner to grant it. | https://docs.subscriby.net/api/v1/errors#token-missing-ability |
| `TENANT_MISMATCH` | 404 | The requested resource does not belong to the team this API token is scoped to. | Use a token minted for the correct team, or switch the creator's current team before minting. | https://docs.subscriby.net/api/v1/errors#tenant-mismatch |
| `RESOURCE_NOT_FOUND` | 404 | The requested resource could not be found. | Double-check the UUID in the path. The resource may have been deleted or never existed. | https://docs.subscriby.net/api/v1/errors#resource-not-found |
