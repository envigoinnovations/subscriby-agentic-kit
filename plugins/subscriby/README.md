# Subscriby plugin for Claude Code

The Subscriby Agentic Kit as one plugin: skills for creators who run a paid community, for developers who integrate the Subscriby REST API and webhooks, and for authors who build a connector on the SDK; slash commands for the daily chores; read-only subagents; a guard that makes every destructive tool ask first; and the hosted Subscriby MCP server, connected through an OAuth sign-in.

```
/plugin marketplace add envigoinnovations/subscriby-agentic-kit
/plugin install subscriby@envigo
```

The marketplace's [README](../../README.md) describes everything inside; the documentation lives at [docs.subscriby.net/integrations/agentic-kit](https://docs.subscriby.net/integrations/agentic-kit).
